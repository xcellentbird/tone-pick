# URL 맵과 히스토리 규칙

## URL

| URL | 화면 |
|---|---|
| `/` | 뿌리 — **여기서 할 수 있는 일이 없다.** 세션이 있으면 자기 회차로 보낸다 |
| `/j/:id/:token` | 회차 확인 + `등록하기` (참가 링크가 여는 곳). **토큰이 곧 신원이다** (ADR-32) |
| `/j/:id/:token/register/1..3` | 등록 3스텝 |
| `/e/:code` | 참가자 메인 · **홈 탭** (스택의 바닥) |
| `/e/:code/people` | 참가자 탭 |
| `/e/:code/p/:nick` | 프로필 시트 (모달) |
| `/e/:code/me` | 내 정보 |
| `/e/:code/seat` | 자리 확인 화면 **다시 열기** (슬라이스 12). 자동으로 뜨는 쪽은 주소가 없다. 보여줄 자리가 없으면 홈으로 **갈아끼운다** — 직접 연 사람에게는 뒤로 갈 자리가 없다 |
| `/e/:code/help` | 파티 룰 도움말 (모달). **상단 물음표로 어느 탭에서든 열리고, 등록을 마치면 한 번 저절로 열린다** (슬라이스 20) |
| `/e/:code/me/edit` | 내 정보 고치기 — **등록 중에만.** 잠긴 뒤에 열면 내 정보로 되돌린다 |
| `/host` | PIN |
| `/host/events` `/host/defaults` | 회차 목록 · 기본 설정 |
| `/host/new/1..3` | 새 회차 위저드 |
| `/host/:id` `/players` `/seats` `/settings` | 콘솔 4탭 |
| `/host/:id/players/:pid` | 참가자 상세 시트 (모달) |
| `/host/:id/players/invites` | 입장 명단 시트 (모달) |
| `/host/:id/seats/:mode` | 테이블 수 고르기 시트 (모달) — `new` · `final` |

**새로고침해도 같은 화면이 나와야 한다.** 참가자 식별은 URL 이 아니라 HttpOnly 세션 쿠키로 한다.

**문은 참가 링크 하나뿐이고, 링크는 사람마다 다르다** (ADR-32).
`/j/:id/:token` 을 열면 **번호를 묻지 않고** 곧바로 등록으로 넘어간다.

- **토큰 없는 `/j/:id` 를 되살리지 마라.** 번호를 아는 사람이 그 사람이 되던 구멍이 그것이었다
- **회차 조회(`/api/events/by-id/:id`)도 토큰을 요구한다.** 경로만 막으면 옆문이 열려 있다
- **`/j/:id/:token` 에 `이전` 버튼을 두지 마라.** 이 화면에 오는 길은 링크뿐이라 앱 안에 돌아갈 자리가 없다
- **입장 코드로 회차를 찾는 길은 없다.** 코드는 `/e/:code` 를 가리키는 이름으로만 남는다
- 링크를 잃으면 운영자에게 **자기 링크**를 다시 받는다. 재발급 화면은 만들지 않는다

통과하면 서버가 서명한 초대 쿠키를 준다 — 번호는 서버가 토큰에서 꺼낸다.
등록 스텝을 오가거나 새로고침해도 다시 묻지 않는다.
초대 쿠키 없이 등록을 시도하면 401 이고, 화면은 `/j/:id/:token` 으로 되돌린다 (replace).
이미 등록한 사람은 링크를 열자마자 `/e/:code` 로 간다.

## push / replace

| 전환 | 방식 | 이유 |
|---|---|---|
| 탭 이동 (홈 탭 → 다른 탭) | push | 뒤로 가기 = 홈 탭 |
| 탭 이동 (그 밖) | replace | 탭을 오가도 히스토리가 쌓이지 않는다 |
| 시트·모달 열기 | push | **뒤로 가기 = 모달 닫기.** 안드로이드에서 가장 중요 |
| 내 정보 고치기 열기 | push | 뒤로 가기 = 취소. 고치던 입력은 버려진다 — 취소 버튼과 같다 |
| 위저드·등록 스텝 | push | 뒤로 가기 = 이전 스텝 |
| 등록 완료 → 메인 | replace | 뒤로 가기로 등록 폼에 다시 들어가면 안 된다 |
| 등록 완료 → 메인 → **도움말** | replace 뒤에 push | 진행 방식을 한 번 밀어준다 (슬라이스 20). **순서를 뒤집지 마라** — 3스텝 위에 얹히면 뒤로 가기가 폼을 밟는다 |

> ⚠️ **`replace` 는 마지막 한 칸만 갈아끼운다.** 등록 스텝은 `push` 로 쌓이므로
> (`이전` 버튼이 그 히스토리를 쓴다) 완료해도 **1·2 스텝이 히스토리에 남는다** —
> 홈에서 뒤로 가면 등록 폼이 다시 떴다. 다 채워진 것처럼 보이는 폼을 보면 두 번 등록하려 든다.
>
> 그래서 **등록 화면도 Join 처럼 "이미 등록했나" 를 먼저 묻는다.** 이미 등록했으면 홈으로 갈아끼운다.
> 히스토리를 손으로 되감지 않는 이유는 되감을 칸 수를 믿을 수 없어서다 —
> 닉네임 중복은 1스텝을 한 칸 더 push 한다.
| PIN 성공 → 콘솔 | replace | 뒤로 가면 로그아웃처럼 보인다 |
| 단계 전환·자리 발송·발표 | 변경 없음 | 데이터 변경이지 화면 전환이 아니다 |

**홈 탭이 스택의 바닥이다.** 참가자는 `홈` 탭, 운영자는 `현황` 탭.
어느 탭에 있든 뒤로 가기 한 번이면 홈 탭으로 오고, 홈 탭에서 한 번 더 누르면 앱을 나간다.

처음에는 탭 이동을 전부 push 로 뒀는데(뒤로 가기 = 직전 탭), 실제로 써보니
탭을 오갈수록 히스토리가 쌓여 뒤로 가기가 "내 발자국 되감기"가 됐다.
사람은 뒤로 가기를 **"목록으로 돌아가기"**로 기대한다. 안드로이드 하단 탭 관례와도 맞다.

## 확인 다이얼로그

실행 **전에** 히스토리를 정리한다. 안 그러면 실행 후 뒤로 갔을 때 처리된 다이얼로그가 다시 뜬다.

```ts
const confirmAndRun = useConfirmRunner();
await confirmAndRun(() => api("/poke", { method: "POST", body }));
```

## 이탈 방지

등록 폼은 `useDraftGuard(hasDraft, "/j/")`. SPA 내부 이동에는 `beforeunload` 가 안 걸린다.
