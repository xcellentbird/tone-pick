# 슬라이스 39 — 파티가 시작될 때 자리가 없으면 자동으로 배정해 보낸다

파티는 예약이 연다 (ADR-93). 그런데 자리는 운영자가 짜서 보내야만 나갔다 — 파티 일시에 폰을 꺼내지 않아도
되게 해놓고, 자리 때문에 결국 꺼내야 했다. **파티가 열리는 순간 보낸 자리가 없으면 앱이 대신 짜서 보낸다** (ADR-106).

`★` 는 반드시 테스트를 붙이는 것 (`test/39-auto-seat.test.ts`).

---

## 범위

**만든다**

| | |
|---|---|
| 언제 | 파티가 열리는 순간 — **예약이 열어도, 버튼으로 앞당겨 열어도** 같다 ★ |
| 이미 보낸 자리가 있다 | **아무것도 안 한다** ★ — 파티 전에 먼저 보내는 것이 여전히 기본 흐름이다 (ADR-39) |
| 짜두고 안 보낸 초안이 있다 | **그 초안을 그대로 보낸다** ★ — 맞바꾼 손이 풀리면 안 된다 (ADR-49) |
| 아무것도 없다 | 등록한 사람 전원으로 새로 짜서 보낸다 ★. 테이블 수는 자리 화면의 기본값(`autoTableCount`, 여섯 명에 한 테이블꼴) ★ |
| 두 명이 안 된다 | 짜지 않는다 ★ |
| 참가자 | 새로 만드는 화면은 없다 — 발행된 자리는 **자리 확인이 먼저**, 그 뒤에 파티 안내가 선다 (ADR-96) ★ 자리 확인을 받는다 |
| 운영자 | 파티 시작 확인창의 `배정된 자리` 줄이 무엇이 나가는지 말한다. 자리 탭은 파티 전에 보낸 자리가 없으면 한 줄로 미리 말한다 |

**만들지 않는다**

- **테이블 수 설정 칸** — 테이블 수는 누를 때 묻는 값이다 (ADR-28). 자동 배정은 자리 화면이 채워 두는 기본값을 쓴다
- **끄는 설정** — 먼저 보내면 자동은 일어나지 않는다. 그게 끄는 길이다
- **새로 온 사람을 초안에 더 앉히는 것** — 초안에서 뺀 사람은 운영자가 뺀 것일 수 있다. 앉히기는 자리 탭에서 한다
