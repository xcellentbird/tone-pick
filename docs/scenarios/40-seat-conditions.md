# 슬라이스 40 — 자리 조건은 자리 탭에서

운영자가 자리 배정의 엣지 케이스 넷을 짚었다 — *참가자로 등록된 운영진 · 지각한 사람 · 먼저 간 사람 ·
특정인과 같은 테이블을 거부하는 사람.* 이 슬라이스는 그중 운영자가 정한 둘을 만든다.

- **뺄 사람은 지난 배정에서 이어받는다** (ADR-108). 운영진은 따로 표시하지 않는다 — 한 번 빼면 빠진 채로 간다
- **떨어뜨려 앉힐 쌍은 자리 탭에서 정한다** (ADR-109). 결과(⛔)를 보는 곳과 고치는 곳이 자리 탭이다

`★` 는 반드시 테스트를 붙이는 것.

---

## 왜 되는가

**ADR-45 가 남긴 약속대로 저장하지 않는다.** 이어받는 목록은 지난 배정의 자리와 등록 시각에서
그때그때 계산한다. 사람에게 붙는 상태가 없으니 낡을 것도 없다. 서버는 그대로다 — `exclude` 는 요청에만 있다.

ADR-45 가 걱정한 것(와 있는 사람이 조용히 빠지는 것)은 **보이는 채로** 막는다 — 시트의 발과
확정 확인창이 빠진 사람을 실명으로 말한다.

## 범위

**만든다**

| | |
|---|---|
| 뺄 사람 이어받기 | 뺄 사람 시트가 **지난 배정에서 빠진 사람을 뺀 채로** 열린다. 운영자는 거기서 고친다 |
| 확정 확인창의 `제외` 줄 | 자리 없이 남는 사람을 실명으로. 셋까지 적고 나머지는 `외 N명`. 0명이면 줄이 없다 |
| 제외된 줄의 모양 | 이어받은 사람이 섞여 열리므로 제외된 줄이 튄다 — 이름은 흐리게, `제외` 는 `--accent` |
| 떨어뜨려 앉히기를 자리 탭으로 | `자리 재배정` 아래 한 줄 → 쌍 목록(`/seats/apart`) → 두 사람 고르기(`/seats/apart/add`) |
| 참가자 상세 시트에서 걷기 | `떨어뜨려 앉히기` 묶음과 `/players/:pid/apart` — 넣는 자리는 한 곳이다 |

**안 만든다**

- **운영진 표시.** 운영자가 정했다 — 첫 배정에서 한 번 빼면 이어받기가 맡는다
- **뺀 사람을 서버에 저장하는 것.** 사람에게 붙는 상태가 된다 (ADR-45). 화면이 지난 자리에서 계산한다
- **참석 상태 · 체크인 · 참가자가 누르는 `도착했어요` 나 `먼저 갈게요`** — ADR-45. 문 앞에서 세는 건 사람이 한다
- **참가자가 고르는 "같이 앉기 싫은 사람"** — ADR-90. 일방적인 마음을 앱이 받는 입구가 된다
- **탭 위에 쌍 이름을 펼치는 것.** 자리 탭은 테이블 번호를 보여 주려고 폰을 내미는 화면이다

## 무엇을 이어받나

**가장 최근 배정**(초안이 있으면 초안, 없으면 마지막으로 발행한 라운드)을 **만들 때 이미 등록돼 있었는데
지금 자리가 없는 사람**이다.

| | 이어받나 |
|---|---|
| 배정할 때 뺀 사람 (운영진 · 안 온 사람) | 예 |
| 그 뒤 `자리 비우기` 를 한 사람 (먼저 간 사람) | 예 |
| 뺐다가 `앉히기` 로 앉힌 사람 (늦게 도착한 사람) | 아니오 |
| **그 배정 뒤에 등록한 사람** (새로 온 사람) | **아니오** |

---

## A. 뺄 사람 이어받기

### S-A1 ★ 지난 배정에서 빠진 사람은 빠진 채로 열린다
```
Given  1라운드를 김가를 빼고 배정했다
When   자리 재배정을 누른다
Then   뺄 사람 시트가 `3명 배정 · 1명 제외` 로 열리고, 발에 `제외 · 김가` 가 실명으로 선다
```
> 접힌 채로도 보인다 (ADR-77) — 조용히 빠지는 사람이 없어야 한다.
> 자리를 비운 사람도 같은 판정이다. 왜 자리가 없는지는 가르지 않는다 — 둘 다 운영자가 뺀 것이다.

### S-A2 ★ 그 배정 뒤에 등록한 사람은 이어받지 않는다
```
Given  1라운드를 짠 뒤에 김라가 등록했다
Then   다음 배정 시트에서 김라는 `배정` 이다
```
> 새로 온 사람이다. 대개 문 앞에서 막 등록했다.
> 섞기·다시 계산은 초안을 만든 시각을 건드리지 않아 이 경계가 흔들리지 않는다.

### S-A3 ★ 초안이 있으면 초안에서 이어받는다
> 가장 최근에 고른 것이다. 초안을 다시 짜려고 `자리 재배정` 을 누른 운영자는 방금 고른 그대로에서 시작한다.

### S-A4 ★ 첫 배정은 전원으로 시작한다

### S-A5 ★ 시트 주소를 바로 열어도 같은 목록이다
> 주소가 진실이다. 새로고침해도, 운영자 폰이 둘이어도 서버 상태에서 같은 목록이 나온다.

### S-A6 ★ 이어받은 사람도 눌러서 다시 넣는다 · 그대로 배정하면 요청에 실린다

### S-A7 ★ 서버는 뺀 사람을 기억하지 않는다
```
When   exclude 없이 배정을 요청한다
Then   전원이 앉는다
```
> 이어받는 것은 화면이다. 서버가 기억하기 시작하면 ADR-45 가 걷어낸 상태가 돌아온다 (`06-seat-edit`).

## B. 확정 확인창

### S-B1 ★ 자리 없이 남는 사람을 실명으로 말한다
```
Given  초안에 김다의 자리가 없다
When   자리 확정하고 알리기
Then   확인창에 `제외 · 1명 · 김다`
```
> 발행의 가장 큰 부작용은 *누가 서 있게 되나* 다 (규칙 4). 초안을 만든 뒤 등록한 사람도 여기 선다 —
> 이어받기 전부터 있던 구멍이다.

### S-B2 ★ 모두 앉았으면 그 줄이 없다

## C. 떨어뜨려 앉히기 — 자리 탭

### S-C1 ★ 자리 탭에는 한 줄만 선다
```
Then   `떨어뜨려 앉히기` 한 줄 — 쌍이 있으면 `1쌍` 이 붙고, 이름은 시트를 열어야 보인다
```

### S-C2 ★ 두 명을 차례로 누르면 그 쌍으로 간다
```
When   두 사람 고르기 → 김가 → 김나
Then   `{a: 김가, b: 김나}` 를 보내고, 확인창·토스트 없이 쌍 목록으로 돌아온다
```
> 맞교환과 같은 손짓이다. 고른 사람을 다시 누르면 풀린다. 누구를 골랐는지는 시트 바닥에 선다.

### S-C3 ★ 첫 사람과 이미 떼어 놓은 상대는 눌리지 않는다
> 넣어도 같은 쌍이라 아무 일이 없는데, 눌리면 된 줄 안다.

### S-C4 ★ 두 번 눌러도 한 번만 간다
> 시트는 닫히는 동안 내용을 붙들고 있다. 한 번 더 눌리면 뒤로 가기가 두 번 걸려 쌍 목록까지 닫힌다.

### S-C5 ★ 빼기는 확인창 없이 간다 · 발표 뒤에는 빼기만 남는다 (ADR-90)

### S-C6 ★ 거절되면 토스트로 말한다
> 시트를 열어 둔 사이 발표가 났을 때 (ADR-8).

### S-C7 ★ 참가자 상세 시트에는 없다
> 넣는 자리는 한 곳이다 (ADR-109).

## 운영자의 하루

```
등록 기간    둘 다 등록한 '떨어뜨려 앉힐 쌍' 을 자리 탭에서 넣는다
첫 배정      뺄 사람: 운영진 · 한 라운드 넘게 늦는다고 한 사람 → 파티 전 발행
             (안 보내도 초안이면 파티가 열릴 때 그대로 나간다. 초안도 없으면 전원으로 짜서 운영진도 앉는다 — ADR-106)
도착         배정 뒤에 등록한 사람 → 검토 카드의 `제외` 칩 → 앉히기
누가 떠남    그 라운드는 `자리 비우기`
동석 거부    자리 탭 → 떨어뜨려 앉히기 → 두 사람 고르기 → 지금 같은 테이블이면 칩의 ⛔ 를 보고 맞교환
다음 라운드  자리 재배정 → 지난 배정에서 빠진 사람이 빠진 채로 열린다 → 돌아온 사람만 다시 넣는다
```
