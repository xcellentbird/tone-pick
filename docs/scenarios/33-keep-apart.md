# 슬라이스 33 — 떨어뜨려 앉히기

운영자가 **같은 테이블에 앉히지 않을 두 사람**을 지정하면, 자리 배정이 그 쌍을 떼어 놓는다 (ADR-90).
지난 파티에서 사이가 틀어진 두 사람이 이번 회차에 함께 오는 경우를 위한 것이다.

**참가자는 이 기능이 있는지 모른다.** 부탁은 현장에서 입으로 받는다 — 참가자가 직접 와서
"자리 배정 때 떨어져 있게 해주세요" 라고 말한다. 앱은 그 말을 운영자 손에 옮겨 줄 뿐이다.

`★` 는 반드시 테스트를 붙이는 것.

---

## 왜 되는가

- **자리는 이유를 말하지 않는다** (ADR-24). 두 사람이 계속 다른 테이블에 앉는 것은 방 안의 흔한 일이다
- **방향이 없는 쌍이다.** `A 가 B 를 피한다` 가 아니라 `A–B 는 떼어 놓는다` 만 적는다.
  누가 부탁했는지는 어디에도 남지 않는다 — 콕을 끝까지 감추는 것과 같은 이유다

## 범위

**만든다**

| | |
|---|---|
| 떼어 놓을 쌍 | 회차 DO 안에 두 참가자 아이디 한 쌍. 방향도 사유도 없다 |
| 운영자 시트 | 참가자 상세 시트 → `떨어뜨려 앉히기` → 상대 고르기. 목록에서 `빼기` (되돌릴 수 있어 확인창 없음) |
| 자리 배정 | `자리 배정` · `AI 섞기` · `섞기` 모두 **동석 0** 을 지킨다 |
| 자리 칩 표시 | 떼어 놓을 상대와 **같은 테이블에 앉은 두 사람의 자리 칩에만** `⛔` 와 글자 |

**안 만든다**

- **참가자 쪽 전부.** 요청 칸도, 등록 화면 안내도, 도움말 한 줄도 없다. 있다고 알리면
  *나를 피한 사람이 있나* 를 궁금하게 만든다
- **운영자에게 따로 말하는 문구.** `N쌍을 떼어 놓지 못했어요` 같은 요약·토스트·테이블 머리글은 없다.
  자리 칩이 말한다
- **사유 메모.** 두 사람 사이의 사정을 앱에 적으면 새면 돌이킬 수 없다
- **콕 막기 · 명단에서 숨기기.** 숨기면 친구 화면과 견줘 드러난다. 서로 콕을 찔렀다면 사이가 풀린 것이다
- **회차 사이의 기억.** 다음 파티에 또 오면 운영자가 다시 넣는다 — 기억하려면 개인정보를 회차 밖으로 옮겨야 한다
- **옆 테이블까지 피하기.** 같은 테이블만 막는다
- **명단(초대) 단계의 지정.** 둘 다 **등록을 마친 사람**끼리만 고른다

## 시나리오

### A. 지정

#### S-A1 ★ 운영자만 넣고 뺀다
```
When   참가자 세션으로, 세션 없이 지정·해제를 부른다
Then   401
```

#### S-A2 ★ 방향이 없다
```
When   A–B 를 넣고 B–A 를 또 넣는다
Then   쌍은 하나다
And    자기 자신은 거절, 없는 참가자는 404
```

#### S-A3 ★ 파티 중에 넣으면 지금 자리에 바로 표시된다
```
Given  파티 중 참가자가 운영자에게 와서 부탁한다
When   운영자가 지정한다
Then   발행된 자리는 그대로다
And    둘이 같은 테이블이면 두 사람 자리 칩에 ⛔ 가 뜬다 — 운영자가 맞교환으로 옮기거나 다음 배정을 기다린다
```

#### S-A4 ★ 발표 뒤에는 넣지 못한다
> 발표가 자리를 끝낸다 (ADR-28). 409. 빼기는 된다 — 남겨 둘 이유가 없다.

#### S-A5 ★ 참가자를 내보내면 그 사람이 든 쌍도 사라진다

### B. 자리 배정

#### S-B1 ★ 떼어 놓을 쌍의 동석은 0
```
Given  남20·여16 · 6테이블 · 5라운드 · 떼어 놓을 쌍 여럿
Then   모든 라운드에서 동석 0 — 씨앗 여러 개로 확인한다 (ADR-57)
```

#### S-B2 ★ 기존 불변식이 무너지지 않는다
> 성비 편차 0, 미배정 0. 나이대 이성 커버는 **씨앗 평균**으로 쌍 없는 판과 견줘 거의 같다.

#### S-B3 ★ 섞기도 지킨다
> 섞기는 붙어 앉은 쌍을 제자리에 두지만(ADR-49), 떼어 놓을 쌍이 같이 앉게 섞지는 않는다.

#### S-B4 ★ 서로 콕 찌른 쌍이어도 떼어 놓기가 이긴다
> 운영자가 사정을 알고 넣은 것이다. 끌림 점수가 규칙을 넘지 못한다.

#### S-B5 ★ 불가능한 판에서도 배정은 나온다
```
Given  2테이블 · 한 사람에게 떼어 놓을 상대가 테이블 수보다 많다
Then   배정은 나온다
And    못 지킨 쌍의 두 사람 자리 칩에만 ⛔ 가 뜬다 — 문구는 없다
```

#### S-B6 운영자의 손 맞교환은 막지 않는다
> 맞교환 결과 같은 테이블이 되면 두 칩에 ⛔ 가 뜨고, 떼어 놓으면 사라진다.
> 운영자가 알고 붙이는 경우까지 막지 않는다.

#### S-B7 ★ ⛔ 는 글자와 함께 말한다
> 색·그림만으로 말하지 않는다 (CLAUDE.md). 칩의 둘째 줄에 누구와 걸리는지 닉네임이 함께 나온다.

#### S-B8 ★ 서로 찌른 쌍이 떼어 놓을 쌍이면 섞기가 붙잡아 두지 않는다
> 섞기는 붙어 앉은 상호 쌍을 제자리에 둔다(ADR-49). 그 쌍이 떼어 놓을 쌍이면 붙잡지 않는다 (ADR-90 후기).

#### S-B9 ★ 늦게 온 사람을 자동으로 앉힐 때 떼어 놓을 상대의 테이블을 피한다
> `autoTable` 이 성비보다 먼저 본다. 시트가 미리 말하는 번호도 같은 함수에서 나온다.

#### S-B10 ★ 떼어 놓을 쌍은 서로 찔렀어도 💘·💔 로 짚지 않는다
> 💔 는 *붙일 수 있다* 는 신호다. 떼어 놓는 맞교환에 `이어진 쌍을 떼어놓습니다` 경고도 뜨지 않는다.

### C. 새지 않는다

#### S-C1 ★ 참가자 응답 어디에도 없다
> `/api/me` · 명단 · 같은 테이블 목록(`mateIds`)에 떼어 놓을 쌍의 흔적이 없다.
> 운영자 콘솔만 `HostState.apart` 로 받는다.

#### S-C2 ★ 참가자 문구에 없다
> 등록 화면·도움말·알림 문구에 이 기능을 가리키는 말이 없다. 문구는 `HOST_UI` 에만 있다.

#### S-C3 지표·콕 로그에 없다
> 지표는 운영자가 자리를 손댄 횟수만 센다 (ADR-58). 쌍 수는 담지 않는다.
