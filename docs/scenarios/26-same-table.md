# 슬라이스 26 — 같은 테이블

참가자 탭에서 **지금 같은 테이블에 앉은 사람**이 목록 위에 묶인다.
`PLAN.md` 26 의 앞 절반이다. 뒤 절반(**지나온 테이블**)은 **만들지 않는다** — 아래 `안 만든다`.

`★` 는 반드시 테스트를 붙이는 것.

---

## 왜 되는가 — 자리는 방 안에서 이미 보인다

지금까지 앱은 *누가 내 테이블인지* 를 한 번도 말하지 않았다. `MySeat` 은 번호와 인원 수뿐이고,
`PublicPlayer` 에 `table` 칸이 없다. 같은 테이블이 나가는 유일한 자리는 **발표 후 · 서로 찌른 상대**의
`MatchInfo.sameTable` 이었다.

그러니 이건 정렬이 아니라 **새 공개**다. 그래도 된다 — 자리에 앉으면 누가 옆에 있는지 눈으로 본다.
앱의 입장도 그렇다 (ADR-24): *같은 테이블에 A·B·C 가 앉아도 B 는 눈치챌 수 없다. 자리는 이유를 말하지 않는다.*
앉은 사실은 열려 있고 **이유만 닫혀 있으면** 된다.

## 범위

**만든다**

| | |
|---|---|
| `MySeat.mateIds` | 나를 뺀 같은 테이블 사람들. **발행된 마지막 라운드 · 내 테이블만** |
| 목록 순서 | 발표 후 = 서로 찌른 사람만 위 (ADR-18) · 발표 전 = 같은 테이블만 위 · 자리 없음 = 무작위 |
| 머리글 | `🪑 3번 테이블 · 같이 앉은 사람` — 사실 한 줄. 묶인 사람이 있을 때만 |
| 아바타 태그 | 같은 테이블 사람의 아바타에 테이블 번호. `나` 태그와 같은 부품 |

**안 만든다**

- **지나온 테이블.** 자리는 한쪽만 보낸 콕도 끈다 (ADR-40). *내가 안 찌른 사람이 자꾸 온다* 는 곧
  *그 사람이 나를 찌른다* 인데, 방은 기억이 흐릿하고 **목록은 정확하다.** 라운드 넷을 나란히 두면 `3번 중 3번` 이 읽힌다
- **다른 테이블.** 전체 배치표는 남들끼리의 패턴(*A 와 C 가 매번 같이 앉네*)을 드러낸다. B 는 A–C 를 몰라야 한다 (ADR-24)
- **이유.** 💘·"커플 자리" 같은 표시는 운영자 것이다 (ADR-51). `서로` 로 시작하는 문장은 없다 (ADR-52)
- **카드 태그.** 이름 줄에 `3번 테이블` 을 더하면 이름이 잘린다 — 목업에서 `여우같은사람 → 여우같…` 이 됐다

## 시나리오

### A. 무엇이 내려가나

#### S-A1 ★ 같은 테이블 사람은 발행된 라운드에서만, 내 테이블만
```
Given  2테이블로 짜서 발행했다
Then   각 참가자의 mateIds = 나를 뺀, seat.table 이 같은 사람들 — 다른 테이블 아이디는 하나도 없다
```
> 참가자 응답만으로 확인한다. 서로의 `seat.table` 이 같은 사람끼리만 서로를 들고 있다.

#### S-A2 ★ 초안은 응답에 없다
```
Then   seat 도 mateIds 도 응답 어디에도 없다
```
> 슬라이스 12 의 규칙이 그대로 이 칸을 지킨다 — `mySeat()` 은 `lastPublished()` 만 본다.

#### S-A3 ★ 지난 라운드의 자리는 내려가지 않는다
```
Given  1라운드(2테이블) 발행 → 2라운드(3테이블) 발행
Then   mateIds 는 2라운드 동석자뿐이다. 1라운드의 둘은 없다
```

### B. 어떻게 보이나

#### S-B1 ★ 발표 전 · 자리 있음 — 같은 테이블이 위, 아바타에 번호
```
Then   같은 테이블 사람이 목록 맨 위 · 머리글 한 줄 · 그 사람들의 아바타에 테이블 번호
And    머리글에도 화면 어디에도 `서로` 가 없다
```

#### S-B2 ★ 자리 없음 — 묶음도 머리글도 없다
> 배정 전이거나, 파티가 시작됐는데 운영자가 안 짰다. 순서는 **보는 사람마다 고정된 무작위**다.

#### S-B3 ★ 발표 후 — 서로 찌른 사람만 위. 같은 테이블 묶음은 없다
> 매칭 카드가 `· 3번 테이블` 로 이미 말한다. 묶음까지 두면 머리글이 **다른 테이블의 짝을 덮어** 거짓이 된다.

#### S-B4 ★ `이성만` 을 켜면 묶음도 걸러진다
```
Given  같은 테이블에 동성뿐이다
When   이성만
Then   묶음도 머리글도 없다
```

### C. 순서

#### S-C1 ★ 같은 사람이 보면 언제나 같은 순서다
> 열쇠가 `해시(나, 상대)` 다. 새로고침·재조회가 목록을 섞지 않는다 — 남이 일으킨 변화에 목록이 움직이면 안 된다 (ADR-64).

#### S-C2 ★ 새로 등록한 사람은 끼어들 뿐, 남들의 상대 순서를 바꾸지 않는다
> 위치를 섞는 게 아니라 사람마다 열쇠를 갖는다. 그래서 한 명이 더 와도 나머지는 제자리다.

#### S-C3 ★ 등록 순서가 아니다
> 그 순서는 곧 *누가 먼저 왔나* 다. 그리고 옆 사람 화면과 다른 순서라 "늘 맨 아래인 사람" 이 없다.

## 어깨너머 가리기와의 관계

무관하다. 가리는 건 **내 콕**이고, 자리는 홈의 자리 카드에서 이미 열려 있다.
가려도 순서는 그대로다 — 슬라이스 16 이 정한 그대로 (순서까지 되돌리면 토글마다 목록이 통째로 움직인다).
