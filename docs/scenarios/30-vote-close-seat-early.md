# 슬라이스 30 — 투표는 시각으로 닫히고, 자리는 파티 전에 나간다

파티 시작 시각보다 **일찍 오는 사람과 늦게 오는 사람**이 있다. 일찍 온 사람은 앉을 데가 없고,
늦게 오는 사람 자리는 비어서 그 테이블 성비가 어긋난다.

`파티 시작` 버튼 하나가 세 가지를 함께 했기 때문이다 —
**① 매력 투표 마감 · ② 자리 공개 · ③ 콕 열기.**
일찍 온 사람을 앉히려면 ②를 ①③보다 앞으로 당겨야 한다.

`★` 는 반드시 테스트를 붙이는 것.

---

## 범위

**만든다**

| | |
|---|---|
| 매력 투표가 **시각으로** 닫힌다 (`voteEndAt`, 기본 파티 −1h) | 마감돼야 자리를 짤 수 있다 |
| 자리는 **발행하면** 보인다 | 파티 전에 온 사람이 자기 테이블을 보고 앉는다 |
| 참가자 카운트다운이 **마감을 센다** | 셀 수 있는 시각이 생겼다 |
| ~~배정 시트의 `뺄 사람` 을 **참석 상태가 채운다**~~ | **되돌렸다 (ADR-40)** — 채워주는 순간 그 목록은 상태의 사본이었다. 목록을 걷어내고 `나감` 만 뺀다 |
| 일정 잠금을 규칙 잠금에서 **가른다** | 파티가 늦어지면 마감도 미뤄야 한다 |

**안 만든다**
- **새 단계.** 마감은 전환이 아니라 **판정**이다 — 알람이 울리지 않고 `phase` 도 그대로 `prevote` 다
- **자동 자리 배정.** 여전히 운영자가 누른다 (ADR-28). 마감은 *재료가 확정되는 때*지 *배정하는 때*가 아니다
- **마감 뒤 늦게 등록한 사람 구제.** 투표를 못 하고 자리에도 없다 → `앉히기` 로 붙는다.
  늦게 온 대가를 정직하게 보여주는 쪽이 맞다
- **참가자에게 "곧 마감" 경고.** 카운트다운이 이미 그 일을 한다

---

## A. 투표가 닫히는 때

### S-A1 ★ 마감 시각이 지나면 투표가 닫힌다
```
Given  voteEndAt 이 지났다
When   참가자가 찌른다
Then   409 · POKE.blocked
```
> 화면이 1초마다 다시 그리지 않는다. 그때 누르면 서버가 같은 이유로 거절하고 토스트가 뜬다 —
> 조용한 쪽이 낫다.

### S-A2 ★ 닫혀도 단계는 그대로다
```
Then   phase 는 여전히 "prevote" 이고 명단·프로필이 보인다
```
> 단계까지 넘기면 나이·MBTI 가 열리고(ADR-21) 콕이 열린다 —
> 아직 아무도 안 온 자리에서 파티가 시작된 것이 된다.

### S-A3 ★ 파티 콕은 마감 시각을 보지 않는다
> 파티 시작과 발표는 운영자가 누르는 것이라 그 사이에 마감할 시각이 없다 (ADR-14).

### S-A4 ★ 마감 시각이 없는 옛 회차는 닫히지 않는다
> 없는 마감을 만들어 조용히 막지 않는다. 이 결정 전에 만든 회차가 프로덕션에 있다.

---

## B. 자리가 보이는 때

### S-B1 ★ 초안은 참가자 응답에 없다
> 화면에서 감추는 것으로는 부족하다 — 개발자 도구를 여는 참가자가 있다.
> 슬라이스 12 가 단계로 막던 것을 이제 **초안**이 막는다.

### S-B2 ★ 파티 시작 전에 발행하면 그 자리에서 보인다
```
Given  매력 투표 단계다
When   운영자가 자리를 발행한다
Then   참가자 응답에 seat 가 있다
```
> 이 게이트를 푼 유일한 이유다. 단계와 자리는 이제 서로를 막지 않는다.

---

## C. 참가자가 보는 것

### S-C1 ★ 매력 투표 중에는 마감까지를 센다
> 세는 순서는 **다음에 일어날 일**이다 — 등록 중이면 투표 시작, 투표 중이면 마감,
> 마감된 뒤에는 파티 시작. **발표는 여전히 세지 않는다** (ADR-14).

### S-C2 ★ 마감이 지나면 할 일 카드가 바뀐다
```
"투표가 마감됐어요 / 자리가 정해지면 여기에 알려드릴게요"
```
> 단계는 아직 `prevote` 인데 할 일이 다르다. **단계 이름만으로는 이 카드를 고를 수 없다** —
> `HOME.todo` 에 단계에 매이지 않은 칸이 처음 생겼다.

---

## D. 일정을 고칠 수 있는 때

### S-D1 ★ 일정은 지나온 것씩 굳는다
| | 잠기는 때 |
|---|---|
| `regOpenAt` | 늘 (만들 때 이미 지남) |
| `prevoteAt` | `fired.prevote` |
| `voteEndAt` · `partyAt` | `fired.party` |

> ADR-35 는 규칙과 일정을 한 잠금으로 묶었다. **파티가 늦어지면 마감도 미뤄야 하는데**
> `fired.prevote` 하나로 일정 전체를 잠그면 손쓸 방법이 없다. 규칙 넷은 그대로 묶여 있다.

