# 슬라이스 09 — 내 정보 고치기

등록할 때 낸 것을 **사전 투표가 열리기 전까지** 참가자가 스스로 고친다.

ADR-27(매력만 고칠 수 있다)의 대상을 넓히는 일이다. 경계는 그대로 `phase === "reg"` 하나다.

`★` 는 반드시 테스트를 붙이는 것 — 어기면 이 앱의 규칙이 깨진다.

---

## 범위

**만든다** — 내 정보 탭의 단일 편집 모드, `PUT /api/me`, 사전 투표 잠금, 잠긴 뒤의 안내 문구.

**고친다** — `PUT /api/me/charms` 를 없애고 `PUT /api/me` 하나로 합친다.
매력만 따로 고치는 길은 남기지 않는다 — 참가자가 하는 일은 "내가 낸 것을 고친다" 하나다.

**안 만든다** — 수정 이력, 운영자에게 가는 수정 알림, 운영자가 참가자 정보를 고치는 길,
"남들에게 이렇게 보여요" 미리보기, 전화번호 수정.
**요청받지 않은 기능을 미리 만들지 마라.**

---

## A. 무엇을 고칠 수 있나

### S-A1 등록할 때 낸 것을 고친다 — 전화번호만 빼고
```
Given  등록을 마친 참가자가 있고 회차는 등록 중(reg)이다
When   닉네임·실명·나이·성별·MBTI·인스타·매력 3가지를 담아 PUT /api/me 를 보낸다
Then   200 이고 응답은 바뀐 Player 다
And    다시 읽어도(GET /api/me) 바뀐 채로 온다
```

### S-A2 ★ 전화번호는 고칠 수 없다 — 입력에 자리가 없다
```
Given  참가자의 번호가 01012341000 이다
When   phone 을 함께 담아 PUT /api/me 를 보낸다
Then   200 이지만 번호는 01012341000 그대로다
```
> **왜** — 파티의 문이 초대 명단의 전화번호다 (ADR-15). 등록 후에 번호를 바꿀 수 있으면
> 문을 우회하는 길이 생긴다. 등록 폼이 번호를 받지 않는 것과 같은 이유고,
> 같은 방법으로 막는다 — **입력 타입에 phone 키를 두지 않는다.** 무시하는 게 아니라 자리가 없다.

### S-A3 등록과 같은 검증을 지난다
```
When   아래를 하나씩 담아 PUT /api/me 를 보낸다
         닉네임이 빈 값 / 16자 / 숫자·특수문자가 섞인 값
         실명이 빈 값 / 숫자가 섞인 값
         나이가 17 / 100 / 정수가 아닌 값
         성별이 "M"·"F" 가 아닌 값
         MBTI 가 네 글자 규칙에 안 맞는 값
         인스타가 빈 값 / 허용되지 않는 글자
         매력이 3개가 아니거나 빈 줄이 섞인 값
Then   전부 400 이고 아무것도 바뀌지 않는다
```
> 화면과 서버가 **같은 함수**를 본다 (`nicknameProblem` · `realNameProblem`).
> 폼을 우회해 API 로 바로 쏘는 참가자가 있다.

### S-A4 닉네임 유일성은 고칠 때도 같다
```
Given  "달빛" 이 이미 다른 참가자의 닉네임이다
When   내 닉네임을 "달빛" 으로 바꾸려 한다
Then   409 이고 error 는 nick_taken, message 는 REGISTER.err.nickTaken("달빛") 이다
And    내 정보는 하나도 바뀌지 않는다
```

### S-A5 내 닉네임을 그대로 두고 다른 것만 고칠 수 있다
```
Given  내 닉네임이 "달빛" 이다
When   닉네임은 "달빛" 그대로 두고 나이만 바꿔 보낸다
Then   200 이다 — 자기 자신과 겹쳤다고 막지 않는다
```

### S-A6 저장은 전부 되거나 전부 안 된다
```
Given  내 나이가 28 이고 "달빛" 은 남이 쓰는 닉네임이다
When   닉네임을 "달빛" 으로, 나이를 30 으로 한꺼번에 바꾸려 한다
Then   409 이고 나이도 28 그대로다
```
> 화면은 이때 닉네임 칸에 에러를 띄우고 **입력값을 보존한다.** 등록 폼과 같은 방식이다.

## B. 언제 고칠 수 있나

### S-B1 ★ 사전 투표가 시작되면 닫힌다
```
Given  등록을 마친 참가자가 있다
When   회차가 prevote 로 넘어간 뒤 PUT /api/me 를 보낸다
Then   409 이고 message 는 ME.locked 다
```
> **왜** — 사전 투표부터 명단이 열린다 (ADR-21). 사람들이 그 정보를 **보고** 콕을 찌르므로,
> 그 뒤에 바꾸면 누군가 나를 고른 근거가 조용히 사라진다.
> 명단이 열리는 순간과 정보가 굳는 순간을 같게 둔다 — 경계를 하나만 기억하면 되게.

### S-B2 파티 중·발표 후에도 닫혀 있다
```
When   party · done 단계에서 PUT /api/me 를 보낸다
Then   409 이고 message 는 ME.locked 다
```

### S-B3 늦게 등록한 사람에게는 처음부터 열리지 않는다
```
Given  회차가 이미 party 단계다 (등록은 발표 전까지 열려 있다)
When   그때 등록한 참가자가 PUT /api/me 를 보낸다
Then   409 다
```
> 그 사람의 정보는 등록 즉시 명단에 보인다. 규칙은 어긋나지 않는다.
> 다만 **화면이 그 사실을 말해줘야 한다** — 버튼만 사라지면 "내 화면만 이상한가" 가 된다.

---

## C. 남의 것은 못 고친다

### S-C1 ★ 세션 없이는 아무것도 못 고친다
```
When   쿠키 없이 PUT /api/me 를 보낸다
Then   401 이고 아무것도 바뀌지 않는다
```

### S-C2 ★ 고치는 대상은 언제나 자기 자신이다
```
Given  참가자 A 와 B 가 있다
When   A 의 쿠키로 B 의 id 를 함께 담아 PUT /api/me 를 보낸다
Then   바뀌는 것은 A 뿐이고 B 는 그대로다
```
> 대상은 **쿠키에서만** 온다. 입력에 담긴 id 는 읽지 않는다.

---

## D. 공개 범위는 그대로다

### S-D1 ★ 고쳐도 응답 경계는 움직이지 않는다
```
Given  참가자 A 가 등록 중에 정보를 고쳤다
When   회차가 prevote 로 넘어가고 참가자 B 가 명단을 읽는다
Then   A 의 항목은 id·nickname·gender·charms 뿐이다
And    realName·phone·instagram·age·mbti 는 응답에 없다
```
> `toPublic()` 한 곳을 지나는 것은 그대로다. 이 슬라이스는 그 함수를 건드리지 않는다.

---

## E. 화면

### S-E1 고치기는 하나다
```
Given  회차가 등록 중이고 내 정보 탭을 보고 있다
Then   `내 정보 고치기` 버튼이 하나 있다
When   누른다
Then   기본 정보와 매력이 **함께** 폼이 되고, 저장·취소도 하나씩이다
```
> 매력만 따로 고치는 버튼은 없다. 참가자가 하는 일은 하나고 잠기는 순간도 하나다.

### S-E2 전화번호는 편집 모드에서도 칸이 아니다
```
When   편집 모드에 들어간다
Then   전화번호는 읽기 전용으로 보이고 왜 못 바꾸는지 한 줄이 붙는다
```

### S-E3 잠긴 뒤에는 왜 못 고치는지 말한다
```
Given  회차가 prevote 이후다
Then   고치기 버튼이 없고 그 자리에 ME.locked 가 있다
```

### S-E4 취소하면 입력이 버려진다
```
Given  편집 모드에서 닉네임을 고쳤고 저장하지 않았다
When   취소를 누른다
Then   화면은 저장된 값으로 돌아간다
```

### S-E5 ★ 편집은 라우트다 — 뒤로 가기가 곧 취소다
```
Given  내 정보 탭에서 고치기를 눌러 /e/:code/me/edit 에 있다
When   뒤로 가기를 누른다
Then   내 정보 탭으로 돌아온다 — 탭을 벗어나지 않는다
And    고치던 입력은 버려진다 (취소 버튼과 같다)
```
> 편집 모드를 화면 상태로만 들면 안드로이드 뒤로 가기가 탭을 벗어나면서
> 고치던 입력이 조용히 사라진다. 폼이 길수록 손해가 크다.

### S-E6 잠긴 뒤에 편집 주소를 열면 내 정보로 되돌린다
```
Given  회차가 prevote 이후다
When   /e/:code/me/edit 를 직접 연다 (링크·새로고침·편집 중 단계 전환)
Then   고칠 수 없는 폼을 띄우지 않고 내 정보 탭을 보여준다
```
