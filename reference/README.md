# 참조용 프로토타입

`poke-party.html` — 단일 HTML 프로토타입. 기획·문구·엣지 케이스가 여기서 확정됐다.

**이식할 때 여기서 그대로 가져올 것**

- 확인 다이얼로그 문구 (무엇이 어떻게 바뀌는지 숫자로 보여주는 형태)
- 단계 전환 안내 문구 `phaseAction()` · 예약 차이 문구 `schedDiffLine()`
- 참가자 알림 문구 `phaseNotices()`
- 자리 배정 `buildSeating()` / `tableCaps()` / `repWeights()`
- MBTI 4문항 토글 문장

**그대로 가져오면 안 되는 것**

- 상태 관리 (`S` 전역 객체) — 라우터 + 서버 상태로 대체
- 공개 범위 처리 — 지금은 클라이언트가 전부 들고 있어 보안이 아니다. 서버에서 걸러야 한다
- 시각 판단 — 클라이언트 시계 기준. 서버 시각으로 옮길 것
